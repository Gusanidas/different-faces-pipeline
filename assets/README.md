# Visual assets

This directory contains only the 20 compact, web-sized figures referenced by
the project overview. Each figure is a contact sheet or comparison matrix; the
individual images used to assemble it are intentionally omitted.

The exact prompts, seeds, generation programs, and measurement programs for the
repeatable experiments live under `experiments/`. Their compact result summaries
live under `data/`. Full generation pools and local curation material belong in
ignored `work/`, not in Git.
